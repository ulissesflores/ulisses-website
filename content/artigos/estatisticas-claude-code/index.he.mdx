עמוד הסטטיסטיקות המקיף ביותר על Claude Code מייחס את מספרי ההורדות שלו לחבילת npm
שמעולם לא הייתה קיימת, עד כמה שהראיות מגיעות. החבילה המצוטטת מחזירה 404 ב־registry
ואין לה ולו תצלום אחד ב־Wayback Machine — אפילו ארכיון האינטרנט לא ראה אותה עוברת.
לחבילה האמיתית, `@anthropic-ai/claude-code`, יש API ציבורי של הורדות שכל אחד שולף
בפקודה אחת: **429 מיליון הורדות מצטברות**, 15.1 מיליון רק בשבוע האחרון. העמוד פרסם
"111,000+". סימן הפלוס מעולם לא עבד קשה כל כך.

מדדתי כל מספר במאמר הזה ישירות במקור — ה־API של npm, ה־API של GitHub,
ה־Wayback Machine, ההודעות הרשמיות, מאגר הנתונים הפתוח של Anthropic. זהו ההמשך שהובטח
ב[מאמר על הסטטיסטיקות של Claude](/artigos/estatisticas-claude): שם אמרתי שמספרי המוצר
של Claude Code יחכו למאמר משלהם. הנה הוא.

> **הערה מתודולוגית.** מושא הבדיקה הוא העמוד "Claude Code Statistiken 2026" של הבלוג
> הגרמני gradually.ai (תצלום Wayback מ־20/05/2026, נתונים המוצהרים כ־"Stand März 2026"),
> המובנה ביותר מבין עמודי הסטטיסטיקות שמסתובבים — וכמו במאמר הקודם, הוא משלם
> את מחיר היותו הטוב בקטגוריה: הוא זה שאפשר לבדוק. ההורדות וה־stars נמדדו ב־API
> הציבורי של npm ושל GitHub ב־11/08/2026; ערכים היסטוריים, בתצלומי Wayback. במקום שבו
> קיימת רק הערכה של צד שלישי, הטקסט אומר "הערכה" ונוקב בשם הצד השלישי.

## המספר שאפשר היה למדוד הוא זה שיצא הכי שגוי

הורדות של חבילת npm הן הנתון הניתן לאימות ביותר במערכת האקולוגית של JavaScript: ה־API
ציבורי, בלי מפתח, בלי חומת תשלום. זה בדיוק המספר שבו העמוד שוגה הכי הרבה:

| מה שהעמוד מפרסם | מה שה־API הציבורי מראה | פי כמה |
|---|---|---|
| "111,000+ הורדות מצטברות" (מרץ 2026) | **44.4 מיליון רק במרץ 2026**; 238 מיליון מצטברים עד אז | פי כ־400 בחודש, פי כ־2,000 במצטבר |
| מקור: `@anthropics/claude-code` | חבילה שאינה קיימת: 404 ב־registry, **0 תצלומים ב־Wayback** | — |
| "22,000+ stars ב־GitHub" (מרץ 2026) | **71,847** ב־01/03/2026, **82,515** ב־25/03/2026 (תצלומי Wayback) | פי כ־3.5 |

עקבות המקור גלויים: מקבץ אמריקאי של "סטטיסטיקות AI" מפרסם את אותם "111,000+ חודשיים"
ואת אותם "22,000 stars" למרץ 2026. העמוד הגרמני חוזר על שני המספרים — ומחמיר את אחד
מהם, כשהוא מקדם "חודשיים" ל"מצטברים". זה הדפוס שכבר הופיע כאן פעמיים: מקבץ מצטט מקבץ,
והמספר מקיף את העולם בלי שאיש יריץ את ה־`curl` שהיה מפריך אותו בעשר שניות.

שתי אזהרות שתקפות למדידה שלי בדיוק כמו לשלהם — מאמר על מספרים שנקראו לא נכון אינו יכול
לבקש קריאה תמימה של מספריו שלו:

1. **הורדה אינה משתמש.** צינורות CI מתקינים מחדש את החבילה בכל build; mirrors נספרים;
   אותו אדם מתקין בשלוש מכונות. ה־429 מיליון מודדים תאוצה והפצה, לא בני אדם.
2. **הסרגל מתכווץ מלמטה.** ה־README הרשמי מצהיר היום שההתקנה דרך npm היא
   **deprecated** — הדרך המומלצת היא המתקין המקורי, Homebrew או winget, ש־npm אינו
   רואה. הירידה שאחרי אפריל בגרף חופפת למעבר הזה (זו השערה שלי, והיא נרשמת בתור
   השערה). כלומר: מ־2026 והלאה, אפילו המספר הענק **מעריך בחסר** את השימוש האמיתי.

## הסקר בקרב 906 אנשים שהפך ל"15,000 developers"

מחצית מהעמוד נשענת על מקור אמיתי וטוב: סקר כלי ה־AI של Pragmatic Engineer, מפברואר
2026. העמוד מציג אותו כ"15,000 מפתחים שנשאלו". הנתונים של הסקר עצמו אומרים דבר אחר:
**906 משיבים**, שנאספו בין 27 בינואר ל־17 בפברואר 2026 — "כמעט אלף", במילותיו של המחבר
עצמו. ה־15,000 הם גודל הקהל שהוזמן, לא גודל המדגם שענה.

האירוניה היא שהסקר לא היה זקוק לניפוח. עם ה־n הכן, התוצאות כבר מרשימות — והן מסתדרות,
אחת אחת, מול הפרסום המקורי:

| מה שהסקר מדד (n=906) | תוצאה |
|---|---|
| כלי ה־AI ה"אהוב ביותר" | **Claude Code עם 46%** — יותר מכפול מהמקום ה־2 (Cursor עם 19%); GitHub Copilot עם 9% |
| בקרב מי שמשתמש בסוכני קוד באופן קבוע | **71% משתמשים ב־Claude Code** (Copilot עם 46%, Cursor עם 39%) |
| אימוץ בחברות קטנות | **75% ל־Claude Code** |
| אימוץ ב־enterprise (10 אלף ומעלה) | **56% ל־GitHub Copilot** — החוזה התאגידי שוקל יותר מההעדפה |
| משתמשים ב־AI לפחות פעם בשבוע | 95% |
| משתמשים ב־2 עד 4 כלים במקביל | 70% |

מדגם של 906 מהנדסים שקוראים ניוזלטר טכני נושא הטיה ידועה — אנשים סניוריים יותר
ו־early-adopters יותר מהממוצע. זו מגבלה שצריך להצהיר עליה, לא להסתיר מאחורי מספר גדול
פי 16.

## שובל ההכנסות: לשני מספרים יש חתימה, כל השאר הד

העמוד מעריך את הכנסות Claude Code ב"כ־2.5 מיליארד דולר במונחים שנתיים, כ־13%
מ־Anthropic". הדרך אל המספרים האלה היא המקום שבו שוכן ההבדל בין מקור ראשוני להד — כי,
בניגוד למה שהיה הכלל בקטגוריה, כאן קיימים **שני עוגנים רשמיים**:

1. **run rate של 1 מיליארד דולר בנובמבר 2025** — הודעה של Anthropic עצמה, מ־3 בדצמבר:
   *"In November, Claude Code achieved a significant milestone: just six months after
   becoming available to the public, it reached $1 billion in run-rate revenue."* שישה
   חודשים אחרי הזמינות הכללית. העמוד הגרמני מתארך את אבן הדרך הזו נכון — ואני מתעד
   זאת, כי בדיקה שמוצאת רק שגיאות חשודה בדיוק כמו עמוד שמוצא רק שיאים.
2. **"יותר מ־2.5 מיליארד דולר" ב־12 בפברואר 2026** — הודעת סבב G, שמביאה באותו עמוד את
   הסך הכולל של החברה באותו תאריך: run rate של 14 מיליארד דולר. החלוקה הכנה היא
   **כ־18%**, לא 13%. ה־13% של העמוד הגרמני יוצאים מחלוקת ה־Claude Code של פברואר
   (2.5 מיליארד דולר) בחברה של מרץ (19 מיליארד דולר, מספר של Bloomberg) — מונה ומכנה
   מחודשים שונים, כשה־run rate צומח בשיעור דו־ספרתי בחודש.

מההודעה הרשמית יוצאים גם מספרי השימוש היחידים שיש להם חתימה: המשתמשים הפעילים
השבועיים של Claude Code **הוכפלו** מאז 1 בינואר 2026, ומנויי business **הוכפלו פי
ארבעה** — צמיחות יחסיות; את הערך המוחלט של המשתמשים Anthropic אינה מפרסמת, וכל
"X מיליון WAU" שמסתובב הוא הערכה של צד שלישי (המצוטטת ביותר מצהירה בגלוי שהיא ניחוש:
"3 עד 6 מיליון" — בספק, הטווח מוכפל). אחרי פברואר, השובל הרשמי הספציפי ל־Claude Code
מתייבש: ה"8 מיליארד דולר במאי" שמסתובב במקבצים חסר מקור ראשוני — סבב H (28/05/2026)
פרסם את הסך הכולל של החברה, run rate של 47 מיליארד דולר, בלי לפתוח את נתח המוצר.
ו־run rate, כתמיד: חודש טוב כפול שתים־עשרה, לא הכנסה שהתממשה.

הסימן העקיף לביקוש, זה כן פומבי ורשמי: בין מאי לאוגוסט 2026, החשבון @ClaudeDevs הודיע
על העלאות והארכות חוזרות של **+50% במגבלות השבועיות** של השימוש
(*"weekly limits are increasing 50%, now through July 13"*; אחר כך,
*"now through August 19"*) — חברה עם עודף קיבולת אינה מבלה רבעון בניהול תור.

## הטענה שהכי קשה היה להאמין לה התבררה כנכונה

"4% מכלל הקומיטים הפומביים ב־GitHub נכתבים בידי Claude Code" נראתה בדיוק כמו אגדה של
רשת חברתית — ובפעם הראשונה שהמספר הזה הופיע לפניי, במאמר הקודם, לא מצאתי את המקור.
מצאתי אותו עכשיו, והוא כפול: ההערכה היא של SemiAnalysis (ניתוח בתשלום, 05/02/2026),
ו־**Anthropic עצמה הדהדה אותה** בהודעה הרשמית של סבב G, עם ייחוס ומה לא:

> "A recent analysis estimated that 4% of all GitHub public commits worldwide were being
> authored by Claude Code—double the percentage from just one month prior."

הסטטוס הנכון, אם כן: הערכה של צד שלישי, שהחברה אישררה במסמך רשמי — לא טלמטריה, לא
מדידה ישירה. הכפלה מ־2% ל־4% בחודש אחד היא סוג העקומה שהופכת להיסטוריה או הופכת
לתקרה; באוגוסט, שום עדכון ראשוני מאותם מחברים לא היה מפורסם.

לעומת זאת, מדדי הביצוע של העמוד לא שרדו את אותה בדיקה: "95% נכונות בניסיון הראשון",
"dashboard ב־React תוך 47 דקות", "test suite תוך 23 דקות" ו"58% ב־SWE-bench במצב
standalone" אינם קיימים באף מקור ראשוני שהצלחתי לאתר — לא Anthropic, לא מאמר, ולא מדד
של צד שלישי נקוב בשם. ה"95%" שבאמת מסתובב הוא משפט אחר: Benjamin Mann (ממייסדי
Anthropic) שאומר ש־95% **מהקוד שלו** נכתב בידי Claude Code — עדות אישית, שניתן לאתר
רק דרך repost, שהעמוד הפך למדד איכות אוניברסלי.

## מה המקור הראשוני אומר כשמישהו קורא אותו — ואיפה ברזיל נכנסת

Anthropic מפרסמת מחקר פתוח על השימוש ב־Claude Code. המאמר מ־16 ביוני 2026 ניתח
**כ־400 אלף סשנים** של **כ־235 אלף משתמשים** בין אוקטובר 2025 לאפריל 2026 — כשהמשתמשים
האינטנסיביים ביותר מבלים 20 שעות שבועיות בתוך הכלי. זהו סוג המספר, עם מתודולוגיה ועם
חתימה, שעמודי הסטטיסטיקות מתעלמים ממנו לטובת "95% נכונות" בלי מחבר.

גאוגרפיה של Claude Code, ספציפית, אין במקור הראשוני: ה־Anthropic Economic Index מפרסם
מיקרו־נתון לפי מדינה עבור Claude.ai, ופלח ה־API מוציא את Claude Code מהפילוחים. לכן
אני מצהיר בדיוק על מה שהמקור הראשוני הקרוב ביותר מאפשר למדוד — ומדדתי, במאגר הפתוח
(CC-BY) של מאי 2026:

ארבע מסתדרות, ארבע שגויות, לשתיים אין מקור שמאפשר לשפוט. הפרט שמארגן את לוח התוצאות:
**כל השגיאות מצביעות לאותו כיוון — כלפי מטה.** העמוד העריך בחסר את ההורדות בשלושה סדרי
גודל, את ה־stars פי 3.5, ואת נתח ההכנסות בחמש נקודות. המוצר האמיתי, זה שאפשר למדוד
ב־API ציבורי, גדול מהמוצר שמתאר העמוד שהיה קיים כדי לקדם אותו.

## מה הייתי עושה עם זה

לפני שמצטטים סטטיסטיקה על כלי AI, שלוש בדיקות שעלותן כמעט אפס: לנתון יש **מפיק נקוב
בשם** (חברה? סקר? מקבץ?) — והמפיק המצוטט הוא המקור או ההד? האם המספר **ניתן למדידה
ב־API ציבורי** (npm, GitHub, מאגר פתוח)? אם כן, מדדו: אלה עשר שניות של `curl`, ובמאמר
הזה השלב הזה הפריך את הנתון שלוש פעמים. והאם המכנה הולך עם המונה — אותו תאריך, אותו
סרגל? השאלה השלישית הזו היא שהפילה את ה"13%".

את השאר — "X% נכונות", "dashboard תוך N דקות" — התייחסו אליו כמו שהוא: מספר יתום. אם
אף אחד לא חותם, אף אחד לא מדד.
